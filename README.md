# EVENTSYNC – AI-Assisted Event Coordination Platform

EVENTSYNC is an AI-powered platform designed to simplify event management by transforming unstructured team communication into clear, actionable tasks.

---

## 🚀 Live Access

- **Frontend App**: [https://event-sync-gamma.vercel.app/](https://event-sync-theta.vercel.app)
- **Backend API**: [https://eventsync-production-6b02.up.railway.app](https://eventsync-production-6b02.up.railway.app)

---

## Problem

Event teams commonly rely on tools like WhatsApp, spreadsheets, and emails for coordination. These tools were not designed for structured execution, leading to:

- Tasks getting buried in chats  
- Unclear ownership and responsibilities  
- Missed deadlines and last-minute confusion  
- No single source of truth for updates  

---

## Solution

EVENTSYNC replaces fragmented communication with a **unified, purpose-built coordination platform** where:

- Team communication happens in one place  
- AI extracts tasks directly from conversations  
- Tasks are clearly assigned and tracked  
- Smart notifications highlight pending and high-priority work  
- Everyone has visibility into responsibilities and progress  

---

## Core Features

### Team & Workspace Management
- Create events/workspaces  
- Add and manage team members  
- Role-based access (admin/member)  

### Real-Time Chat
- Centralized team communication  
- Structured messaging environment (no lost information)  

### AI Task Extraction
- Automatically converts chat messages into tasks  
- Detects:
  - Task description  
  - Assignee  
  - Deadline  
  - Priority  

### Task Management Dashboard
- View all tasks in one place  
- Filter by:
  - User  
  - Status  
  - Priority  
- Update, edit, or complete tasks  

### AI-Powered Notifications
- Smart reminders for upcoming deadlines  
- Alerts for overdue tasks  
- AI-generated summaries of high-priority work  

### Human-in-the-Loop Confirmation
- AI suggests tasks  
- Users review and confirm before assignment  
- Ensures accuracy and builds trust  

---

## Goal

To reduce miscommunication, improve accountability, and eliminate last-minute event execution failures by creating a structured, intelligent coordination system for teams.
